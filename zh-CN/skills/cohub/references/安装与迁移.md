# 安装与迁移

只安装 cohub 的一种说明语言：英文目录 `skills/cohub`，中文目录 `zh-CN/skills/cohub`。两者功能、名称和版本相同，language 分别为 en 和 zh-CN。发行包必须完整保留 references、scripts 和 version.json，不能只复制 SKILL.md。

## 安装前

1. 使用宿主文档或已知配置确认实际 Skill 搜索目录，不猜固定路径、不扫描整个用户目录。检查已知项目级、用户级和插件级目录，解析符号链接并按真实路径去重；说明检查范围，未覆盖位置不能声称无重复。
2. 查找名称为 cohub 或 cohub-app-developer 的现有入口，读取版本、说明语言和用户定制；没有元数据就是未知，不依据用户对话语言推断已安装语言。
3. 首次安装让用户选择说明语言；未指定时建议沿用当前交流语言，并明确告知选择。升级保留原语言，未知时先确认；切换语言须是用户明确意图。
4. 多份活跃安装或旧独立 App Developer 存在时，先列出路径、语言和版本，确定保留哪份。暂停新增安装，不静默覆盖、删除或移动文件。

## 迁移与验证

2.0.0 将 App Developer 收入 references/app-developer，不再提供独立 Skill。先比较已有两个 Skill 的定制，再将适用内容合入经确认的单一 cohub 安装。移除或禁用旧入口需要明确授权；使用宿主支持的禁用方式，备份不留在会被扫描的 Skill 目录中。共享挂载、插件缓存或归属不明时，不擅自修改。

正式安装从已发布 tag 的所选语言目录取得，不从 main 候选版安装；明确要求试用开发版时才用 main，并标为未发布。将版本称为正式版前，核对公开发布指针。

验证宿主实际只发现一个 cohub、没有活跃的旧 cohub-app-developer；检查全部相对引用和包内版本语言一致。无法观察宿主发现结果时明确未验证，不以文件复制成功代替。保留自定义内容及既有 Init 清理状态。

报告：Cohub Skill 版本、说明语言、实际目录、正式或开发版，以及“说明语言不会改变 Agent 的对话语言”。不要修改宿主语言、全局指令或用户偏好。

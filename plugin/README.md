# Cohub Cards

在 Codex 聊天里一起创作图片、视频、语音和音乐。

默认是一张 Cohub 风格的创作卡：上方是作品舞台，下方是和 Cohub 聊天输入框一样的描述框，带模型、常用参数和生成按钮（`⌘↵`）。需要更多设置时点 **展开编辑**，右侧面板列出全部参数和参考素材；点 **返回聊天** 收起。你和 Agent 编辑同一份草稿，Agent 改动后卡片会标出“已同步最新内容”。

图片、视频或音频可以直接拖进卡片，或粘贴到描述框，作为参考素材。界面规范见 [DESIGN.md](DESIGN.md)。

## 已安装的用户怎么用

直接在 Codex 中说：

> 用 cohub 准备一张海岸图片，先不要生成。

无需记住插件全名。也可以直接说“帮我画张图”“让这张图片动起来”“给这段文字配音”或“做一段背景音乐”，让 Codex 根据创作需求匹配此插件。明确指定其他工具时仍遵循你的选择。自动匹配由 Codex 判断，不是固定关键词开关。

首次使用告诉它要用哪个 Cohub 空间。然后可以：

- 在卡片里查看完整方案和预计费用，修改描述后点击“确认并生成”，无需再发确认消息。
- 展开“修改方案与查看详情”，可修改方案说明，或点“取消，保留草稿”。
- 继续聊天：“改成暮色，保留我刚调好的设置。”
- 点击“展开编辑”，调整参数、添加参考图片或声音。
- 说“准备一段配音”或“准备一首背景音乐”，打开对应创作卡。

每次创作先在卡片展示 brief：方案与思路、完整提示词、参考素材、产出规格及预计消耗。用户直接点击确认，不需要再发一条聊天消息。保存期间不能确认；方案、模型设置或报价变化后必须重新查看。取消会保留并暂停草稿。

多份独立草稿准备好后，可以在主卡片勾选“本次任务内自动继续”，选择草稿并填写预计费用预算，一次确认后依次提交。只覆盖这次选中的内容，不会自动新增步骤。费用未知或超出预计预算时需逐项确认；实际扣费以 Cohub 为准，填写的预算不是服务端硬性扣费上限。中途失败会停止，保留已提交记录及未提交草稿。

也可以主动说“这次由你自行确认，预算不超过……”，让 Agent 在指定范围内操作。普通的“做个视频”或“继续”不代表这种授权。准备和编辑草稿不提交生成。

## 朋友如何安装

目前提供源码安装，已在 macOS 的 Codex 桌面端验证。其他系统尚未实测。

准备好：

1. 支持插件和聊天内卡片的 Codex 桌面版。
2. Node.js **24 或更新版本**、npm、Git，以及可执行的 `codex` 命令。
3. Cohub 账号、可用空间和官方 CLI：

```sh
npm install -g @neta-art/cohub-cli
cohub auth login
```

下载安装：

```sh
git clone https://github.com/atou42/cohub-plugin.git
cd cohub-plugin
bash scripts/install.sh
```

安装完成后，完全退出并重新打开 Codex，然后使用上面的示例开一张创作卡。保留克隆目录，后续更新需要它。

安装脚本会下载锁定版本的依赖、构建卡片并注册本机插件市场，不会生成作品或上传素材。每位用户使用自己的 Cohub 登录，仓库不含作者的账号、草稿或测试作品。

**不要直接把 GitHub 地址添加成插件市场。** 当前发行方式需要先构建并安装运行依赖；上面的安装脚本会完成这些步骤。

## 更新

在克隆目录中执行：

```sh
git pull --ff-only
bash scripts/install.sh
```

完成后重启 Codex。升级不会删除已有草稿。

## 范围与数据

- 图片、视频、语音和音乐使用同一套卡片。可用参数、素材用途和价格读取 Cohub 的模型声明。
- Higgs 默认音色和单条参考音频可用；多音色混合所需的权重尚未被官方 CLI 支持，卡片会明确阻止该组合。
- 草稿默认保存在 `~/.local/state/cohub-cards`。插件不另存登录凭据。
- 本地参考素材每个不超过 20 MiB。点击生成时会上传到所选 Cohub 空间的公共素材地址，供模型读取。
- 提交结果不明时不会自动重试，避免重复生成和收费。
- 应用发布由官方 Cohub CLI 执行，插件展示发布结果。复杂画板编辑继续使用 Cohub 已有的 Board。

## 开发

```sh
npm ci --ignore-scripts
npm test
npm run build
```

自动检查覆盖共享草稿、完整方案确认、取消、报价变化、预计预算、批次中断、重复提交防护、快捷键和卡片切换。旧版已在原生 Codex 中实测展开、同步及返回聊天；新增确认流程的模拟验证不等于原生宿主验收。此前已通过真实图片、视频、语音和音乐生成测试，未逐一付费测试全部模型。

架构说明见 [ARCHITECTURE.md](ARCHITECTURE.md)。真实账号验收记录和本机预览不随仓库发布。

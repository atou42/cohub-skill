# 创作能力准备与验收

只读取本次所选能力。先按主入口直达远端说明；下表是已知依赖，不替代当前包中的具体命令。不得编造安装器、文件清单、健康检查或路径。

| 能力 | 必需内容与依赖 | 低风险就绪检查 | 交付判断 |
|---|---|---|---|
| Style | AGENT_GUIDE.md 与同目录 catalog.json；实际生成另走生成模块 | 解析 catalog.json，确认所选条目及参考素材可读 | 记录所选风格；生成任务另验收真实素材 |
| Game Maker | 所选子 Skill 及其引用的 runtime、assets、模板、工具和同级模块；按当前入口核对 Neta CLI、生成服务、抠图或 CDN 依赖 | 解析包内清单及项目脚本；检查运行时与依赖版本；仅运行已检查且不产生付费或远端写入的验证命令 | 游戏可启动、关键交互与素材正常；发布单独验收 |
| Fandom | 当前入口描述的 HTTP API、所需认证及引用；不臆造 Fandom CLI | 先核对接口契约，获授权后做一次当前入口支持的只读查询 | 返回相关内容、出处和实际可用的图片引用 |
| OKP search | 当前入口要求的独立 CLI、认证和领域 schema | 本机帮助、当前入口指定的只读身份检查及 schema 读取 | 返回有出处的匹配结果；不执行导入、写入或导出 |
| Character Traits | 所选入口引用的数据、脚本及依赖；解析旧 ~/.claude 路径而非假设存在 | 检查引用文件是否齐全；先读脚本再运行其提供的无副作用验证；没有检查器时如实说明 | 产出所需角色性格、矛盾和成长材料，与用户已有设定一致 |

## 获取与执行

- 只在需要执行包内工具时落地包。使用项目中经确认、未占用的任务专用目录，不全局安装为另一个 Skill、不覆盖已有项目目录。记录实际本地根目录。
- 以当前入口、manifest 和相对引用确定必要文件；保留目录结构，解析旧环境绝对路径。不能确定依赖闭包时列明缺失项，不能只拿入口就宣称就绪。
- 记录 Space ID、入口路径、读取时间和入口内容摘要；有上游版本/快照 ID 时一并记录。优先同一快照；无快照接口时记录关键文件摘要，完成获取后重查入口是否变化，发生变化先核对一致性，不混用后继续宣称固定版本。
- 记录命令、输入、依赖和验收方式。信息足以完成当前步骤时停止找资料。保留本次取得且仍适用的证据。
- 安装依赖、执行脚本、付费生成与发布分别遵守当前授权。脚本未经检查不运行；无权读取只阻塞该来源，不能改权限或替换受限来源。
- 分别报告来源可读、文件齐全、依赖就绪、执行成功、产物可用和访客路径验证。未执行的阶段不能推断成功。不要为“就绪检查”创建付费任务。

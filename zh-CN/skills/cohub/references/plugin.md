# 可选的插件交互

插件包含同一份 Cohub Skill，增加共享草稿与结果展示。独立 CLI 工作不需要插件。Codex CLI 也能加载插件：工具是否可用、宿主是否能显示卡片是两件事。

## 选择交互方式

- Cohub 插件工具可用时，生成使用共享草稿，除非用户明确选择直接 CLI。宿主支持卡片时调用 `prepare_generation` 展示可编辑卡片，不用浏览器链接或截图代替。展开详情和返回聊天共用原草稿。
- 工具可用而宿主没有卡片时，在对话中展示同一份已保存草稿与完整方案；用户明确文字批准后，可对当前版本调用 `submit_generation`。没有卡片显示能力不等于插件故障。
- 没有插件工具时，按[生成](生成.md)使用文字方案和官方 CLI，不要求安装插件。用户明确选择卡片流程后出现工具故障或缺失，应说明并排查，不静默换提交路径。换路径前核对原次提交；结果不明绝不重提。
- Cohub 图片、视频、语音、音乐的自然需求直接进入此流程，不要求工具名。咨询能力或讨论创意不自动创建草稿或任务。项目同步、会话导入、游戏制作沿用各自路由。用户明确选择其他产品时遵循其选择。

## 同一份共享草稿

遵循[创作方案与授权](创作授权.md)。方案与创作取舍写入 `brief.summary`，产出范围写入 `brief.output`；完整提示词、参考素材、模型与参数放入各自字段。读取官方模型费用，不编造报价。卡片可见时聊天简短引导查看，不重复整份方案。

| 工具 | 使用方式 |
| --- | --- |
| `prepare_generation` | 每份新创作调用一次，填写 `spaceId`、`model`、`prompt`、`media`、`parameters`、`meta`；选模型期间可留空。保存返回的 `draft.id`。 |
| `read_generation_draft` | 编辑或提交前读取最新内容、`draft.revision`、模型声明及校验结果。 |
| `update_generation_draft` | 传 `draftId`、当前 `baseRevision` 和 `patch`。`media`、`parameters`、`meta` 是整值替换，先与用户最新内容合并。 |
| `add_generation_reference` | 使用同一草稿、当前版本、媒体 `type`，以及一种来源：HTTPS `url`、已授权本地 `filePath` 或文件选择器的 `base64`；按模型声明保留 `role`。 |
| `submit_generation` | 当前方案已批准，或在明确的任务内自主授权范围内时才提交。重读当前内容并核对授权，使用当前 `baseRevision`。 |

遇到 `REVISION_CONFLICT` 重读并合并所需修改，保留用户最新输入。不反复提交旧版本，也不另建草稿绕过冲突。

按返回的官方模型声明保留类型、输入、角色和必填参数；需要时只读查询 `cohub models ls --model-type multimodal --json` 与 `cohub models show <model> --json`，不猜字段。Higgs 当前支持默认音色或单条参考音频；官方 CLI 不支持带权重的多音色混合，不能省略权重后声称已实现。

本地素材先暂存，单个上限 20 MiB；提交时上传到所选 Space 的公共素材地址。只添加用户选择或已授权素材，批准前说明传输方式。私有输入或禁止公开上传的要求不适合此插件路径：提交前说明限制，用户选择直接 CLI 后按其支持的 `--inline` 处理。不能静默切换或公开上传。

## 确认与暂停草稿

卡片“确认并生成”直接提交，无需再发聊天消息。用户审阅后明确文字批准，也可以授权 Agent 提交同一份未暂停草稿。Agent 不调用仅供卡片的 `confirm_generation`、`cancel_generation`，也不代替用户操作控件。

卡片确认绑定展示时的草稿版本、模型设置和报价；变化后须重新审阅确认。取消后 Agent 修改不会解除暂停。卡片暂停的草稿只能由用户通过确认控件恢复；文字批准或自主授权不能让 Agent 覆盖该暂停状态。宿主没有所需控件时说明限制并保留草稿，不另建替代。已批准的文字方案不重复询问，但仍须遵守已有暂停及过期确认检查。

## 卡片的有限批次

同一 Space 中已准备好的独立草稿，可把最多 19 个后续 ID 写入主草稿 `continuationDraftIds`，先准备再列入。用户勾选草稿、填写预计费用预算并选择本次任务内自动继续后，只顺序提交这些已审阅草稿；不授权新方案、改提示词或依赖前一步产物的阶段。

报价未知、预计费用超出预算、草稿或报价变化时停止。出错保留回执与未提交草稿；已经停止的批次不能作为批次恢复或重试。逐项读取原草稿核对完成情况，未提交的选择保持暂停。预算核对当前可确定报价，不是服务端扣费硬上限。缺少确定费用的模型仍可逐项确认。有限批次选择与[创作方案与授权](创作授权.md)中明确授予 Agent 的更广自主权不同。

## 回执与交付

`submitting` 时继续读原草稿；`unknown` 或响应不明时核对原次提交，不重提或另建重复草稿。`submitted` 后保存 `taskRunId` 供查询。展示失败只恢复读取；用户明确要求新修改时，另建草稿引用原任务真实产物。费用以实际 billing 为准，缺记录不写成零。

已有任务使用 `show_generation({spaceId,id})`。发布按[发布](发布.md)使用官方 CLI，并遵循相同授权规则。通过 `cohub -s <spaceId> apps get <appId> --json` 读回真实链接、版本与可见性，工具可用时再调用 `show_publication({spaceId,id})`。封面来自 App 真实 `meta.image` 或已验证截图。保留发布卡要求的事实交付信息。分别说明发布结果与功能检查结果；只有在实际宿主测试后才能宣称原生交互已验证。

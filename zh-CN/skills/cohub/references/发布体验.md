# 发布后，让真正的使用者完成目标

用于 Cohub 发布前后按项目用途检查交付。沿用已确认的设计和功能；仅发布现有作品时修复必要的发布问题，不自动重设计、加登录、加 AI 或收费。较大的体验改动作为建议，不阻塞用户明确选择的现状发布；演示中的未实现功能应如实标明。

## 从使用目标决定检查范围

从已有项目与对话确认谁会打开、第一次应完成什么、主要使用设备。信息已有就不重新访谈。检查承载方式与运行依赖时，分开判断前端静态文件、外部服务与 Cohub runtime：静态前端也可能调用在线接口，能打开 HTML 不代表离线可用，有后端也不意味着必须迁移。

仅有成品链接时，可检查公开界面，但不能据此推断已取得源码、后端和发布权。需要修改的源码缺失时只索取必要部分；不要把私有服务代码、密钥或整个工作目录打进公开产物。

保留外部服务时，在新的公开入口实际检查浏览器请求、允许的来源、HTTPS 与身份配置；不把私钥搬进前端来修复访问。承诺离线使用时区分下载后本地运行与加载后断网，按所选范围验证素材和核心操作，不承诺首次打开在线分享链接无需网络。

## 首次打开与核心流程

根据实际用途选相关项，不要求所有 App 都实现整张清单：

| 作品用途 | 实际走到的结果 |
|---|---|
| 报告、作品集 | 首屏说明内容与适用范围；最新结论容易找到，历史结果标明日期；图表、样片和下载可用 |
| 游戏 | 找到开始入口，完成一轮主要玩法，能按设计重开；涉及触屏时实际检查触屏操作 |
| 编辑或生成工具 | 送入一个有效输入，看到处理状态，取得并打开可用结果；保存、复制或下载按已承诺的用途检查 |
| 数据应用或在线服务 | 首次无数据时知道下一步；读取、提交或保存完成；需要保留的数据按承诺在刷新后仍存在 |

在约定屏幕上实际查看首屏、主要操作、长内容和结果区域；文字应可读，主要按钮可触达，不能被 Cohub 外层工具栏遮挡。检查图片、字体、音视频、相对路径和适用的深层链接/刷新。不要为统一外观强加某种配色、导航、动画或固定页面结构。

公开分享时沿用或补齐能辨认作品的页面标题、简短用途说明和已有图标；涉及分享预览图时核对当前 Cohub 实际支持及展示，不凭填写元数据就宣称预览生效。生成工具的首屏应让使用者知道要提供什么、会得到什么；需要示例时使用已获授权的素材，不能用预制结果伪装实时生成。不要把 Space ID、scope 或部署步骤塞进普通使用者流程。

只覆盖项目会遇到的状态：初次空白、运行中、成功、失败；有登录或授权时再查拒绝和过期，有付费能力时再查费用说明与余额不足。错误说明应保留用户输入、已取得结果和可执行下一步，不把故障显示成“没有数据”或无限等待。

## Cohub 身份、生成与费用

静态阅读无需为了测试而接入账号或生成。只有用户选择运行时能力，才读取 [App Developer](app-developer/入口.md) 对应模块，并核对当前文档与实际版本。

- 分别确认谁能打开页面、谁能调用功能、结果存在哪里、谁承担平台成本；公开 App 不等于匿名生成，也不等于公开 Space。
- 保留已有后端或选择 Cohub 接入取决于用户目标。接入时按真实 runtime 获取身份，不把作者凭据放入前端，也不强制所有应用迁移到同一种调用方式。
- 不把 Neta 的新用户赠送积分、申请免费额度或扣费机制移植为 Cohub 承诺。访客商业积分与平台余额分别核对；App Action 的作者执行成本与访客权益不是一回事。
- 按实际承诺测试作者之外的访问路径：公开阅读可匿名检查；登录后使用需获授权的普通使用者身份。没有账号、预算或相应工具时明确未验证的部分，不擅自注册账号、发起购买、扩大权限，或用作者态代替。
- 对生成工具，在原有授权内走到真实结果及可用输出；任务编号或成功提示不能代替成片。不能进行真实生成或扣费验证时，分别标注页面检查、模拟检查和真实使用尚未验证。

## 从症状继续，不先认定原因

| 可见症状 | 查证方向与继续条件 |
|---|---|
| 页面打开但素材丢失 | 核对请求地址、发布目录和资源权限；修正所证实的问题后在公开版本复查，不一律替换为绝对路径 |
| 按钮无响应或一直等待 | 区分事件未触发、服务请求失败、任务仍在运行和结果读取失败；已有任务继续查原任务 |
| 作者可用，朋友不可用 | 对照实际测试身份、数据范围、授权和费用承担；不默认全开权限，不假定作者一定绕过所有检查 |
| 重复点击出现冲突 | 先确认原操作状态与资源归属；按语义复用同一操作或明确新建。不能只按同名复用其他用户会话，也不能靠随机改名制造重复任务/费用 |
| 分享后出现嵌套页面或重复工具栏 | 检查实际返回的 Cohub App 入口和嵌入层级；修正重复包装，不把裸素材 CDN 地址冒充 App 分享入口 |
| 上传中断、限流或发布状态不明 | 保留已知上传和 App 状态；按返回的恢复信息处理，先确认是否已发布再重试。不能假称 CLI 支持续传；不支持时明确阻塞，不删除作品、换账号或反复全量提交 |

## 分享前的完成依据

在返回的真实 Cohub App 链接验证承诺的主要流程；本地预览不能替代 runtime、访客身份和费用验证。区分页面发布成功与全部功能可用。

仅到发布结果交付时再读取[发布卡](发布卡.md)；此处不预加载卡片或它引用的其他文件。更新已有作品时确认同一对象、约定可见性、新版本和稳定入口；保留可恢复的源码及发布产物。用户反馈问题时从具体状态继续，不要求其学习平台实现。

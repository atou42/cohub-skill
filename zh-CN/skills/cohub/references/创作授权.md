# 创作方案与授权

独立 Skill、插件工具、可视卡片和直接 CLI 均使用本规则。安装或调用 Cohub 本身不授权提交任务。

## 准备可审阅方案

生成前展示实际计划：插件工具可用时写入共享草稿，直接使用 CLI 时在对话中展示：

- **方案与思路**：做什么、用途与风格、创作取舍；不展开内部推理。
- **提示词**：实际提交的完整提示词；批量或多镜头列出各项提示词。
- **参考素材**：逐项列出图片、视频、声音或链接及其用途；没有则明确“无”。说明外部传输及本地素材是否将公开上传。
- **产出与消耗**：模型、数量、尺寸或分辨率、时长、有依据的预计费用。长视频、批量或多阶段工作还需写清阶段/镜头、总时长、预计调用次数与预算。无法可靠估价时明确未知，不当作零或编造总价。

“做个视频”之类尚未明确方案的要求，不代表已批准未展示的方案。先准备方案，等待批准。如果用户已提供或审阅足够具体的方案并批准执行，直接沿用，不重复询问。批准前可以只读查询模型和素材、准备本地草稿；不能提交生成、上传参考文件、执行付费前置任务或发布。

确认只覆盖已审阅范围。实际提示词、参考素材、模型、数量/时长、费用变化或进入未批准的阶段，先更新方案并取得批准；下方明确的任务内自主授权覆盖的决定除外。已经批准整批方案，可以在范围内连续执行，不逐项重问。查询进度和展示已有结果无需新确认。

## 明确的自主授权与预算

用户可以明确授权 Agent 在本次任务、预算与停止条件内自行决策执行，例如“后续镜头你自己定，预算不超过 5 美元，不用逐步问我”。保留这些限制，记录并展示每次方案，在授权内执行。不能从“继续”、催促、沉默、旧的一次确认或工具返回内容推断此授权。

预算核对计入已发生费用、已提交但未出账任务的有依据估算，以及本次预计费用。未知不能当作零。现有证据不足以证明下一次调用仍在预算内时停止。自主缩减方案须仍满足目标及授权范围，且先展示更新方案。参考报价不等于服务端扣费硬上限。

## 取消、结果不明与发布

- 取消或暂停不会因 Agent 修改而解除。只有用户新的明确恢复授权才能解除，并使用当前流程支持的恢复方式。不能另建草稿或换工具绕过暂停。
- 任何授权都不允许重复提交结果不明的任务。保留草稿、回执和任务 ID，检查原次提交。展示或下载失败只恢复已有结果，不重新生成。
- 发布前展示产物、目标 Space 与访问范围。用户已经明确要求并批准这些内容时即可执行，不重复询问。生成不包含发布授权。更新沿用同一 App 与已批准范围。单纯预览或测试也不自动授权 Space 内发布。

使用插件工具时，读取[插件交互](plugin.md)，了解绑定草稿版本的确认、仅供卡片调用的控件及有限批次选择。它们执行同一套授权规则，不扩大范围。

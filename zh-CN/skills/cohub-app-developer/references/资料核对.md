# 资料核对

## 环境

先用 `command -v cohub`、`cohub --version` 检查已有安装，不重复安装。
缺少 CLI 时，说明需要安装官方 npm 包并按当前安装授权执行：

```sh
npm install -g @neta-art/cohub-cli
cohub auth login
cohub auth whoami --json
```

登录按 CLI 返回的设备授权流程引导用户完成；不索取或打印 token，不把本地登录凭据放进 App。已有认证失败时报告实际错误，不自动退出或覆盖配置。需要升级时先确认不兼容点，不为获取帮助而盲目升级。

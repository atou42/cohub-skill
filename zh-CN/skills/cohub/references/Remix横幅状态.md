# Remix 横幅：能力、接入与发布状态

仅在填写发布卡的 Remix 横幅、用户询问或要求接入改作能力时读取。名称保留“Remix 横幅”，与顶部“数据显示栏”分开报告。

## 当前已核实的能力

2026-09-19 对照 Cohub Space、官方仓库 main（`78d643c7f7d008fc72fd5e7ff33407628fb75864`）及 CLI 7.0.1：**所核对的标准 App 发布与分享页链路没有内置 Remix 横幅、开启参数或 App 一键复制流程**。不要继续用“尚未确认开启方式”暗示存在一个尚未找到的开关，也不要推断所有版本、Neta Studio 或作者自建页面均无此功能。

依据：
- `packages/sdk/src/apis/apps.ts` 的 `AppPresentationMeta` 只有 `hideCohubBar` 与 `surface`；`AppPublishDialog.svelte` 的显示设置只控制 Cohub bar。
- `apps/web/src/routes/(public)/[username]/[spaceSlug]/w/[appSlug]/+page.svelte` 与 `AppSurface.svelte` 的分享页渲染没有 Remix 入口；`CohubBar.svelte` 展示品牌、作品、作者、浏览量和版本操作。
- `apps/worker/src/system/jobs/app-publish-asset/index.ts` 的发布打包流程没有注入 Remix 横幅。当前 `cohub apps --help` 没有 remix 子命令。
- CLI 确实支持 `apps download`：本次对已发布 directory App 实测下载成功，并核对下载文件与原稿一致。这验证了下载能力，没有验证新访客一键改作。

上述路径位于[官方仓库](https://github.com/talesofai/cohub/tree/78d643c7f7d008fc72fd5e7ff33407628fb75864)。未来出现实际横幅、新版本说明或配置时，沿该入口查证并更新本结论，不机械套用旧结论。仅凭页面没有入口也不足以证明平台不支持。

## 用户想基于作品继续创作时

当前可执行的路径是：**取得已发布文件 → 在独立目录修改 → 预览验收 → 发布为新的 App**。它是 Agent 辅助改作，不是平台一键 Remix。

1. 识别来源 App 和版本，在当前登录身份下读取详情；确认内容可下载和用户有权使用。公开可访问不等于提供改作许可。
2. 用当前 CLI 帮助核对参数，下载到新的工作目录，保留原作品：
   ```sh
   cohub apps download '<来源 App 链接或 ID>' --output '<新的工作目录>' --json
   ```
   确认返回的版本、文件和实际内容。单文件与目录按返回的 kind 处理；不可下载或拒绝访问时报告原始原因，不绕过权限。
3. 检查下载包是否具备修改所需素材和代码。发布文件不保证包含原始工程、依赖源码或外部服务；生成、登录、Actions、存储和收费配置必须单独核对，不能声称原 App 的权限、账户、历史数据、商品或服务已复制。
4. 按用户要求修改并验收。需要发布改作时，走[发布](发布.md)，使用新的 App 身份和名称，返回新链接及来源信息；除非用户明确要求修改原作，否则不能更新原 App。

## 用户希望访客看到 Remix 横幅时

先说明当前标准分享页不自动提供该入口。若用户要求实现，可在作品中接入**自建改作引导**，但不得把它称为平台自带一键 Remix，也不因填写发布卡就擅自改页面。

最小可用引导应提供作品来源、允许改作的内容、获取文件的方法，以及可复制给 Agent 的改作说明，例如：“基于这个作品制作我的版本：<来源链接>。请先检查是否能取得完整文件，再按我的要求修改；发布时创建新作品，保留原作。”不要编造 Cohub 的预填提示链接、Remix API 或 metadata 开关。

若要求“一次点击就创建可编辑副本”，必须额外实现并验证目标空间选择、实际文件复制、依赖处理和新作品创建。不能把跳转首页、复制一句提示或仅下载文件验收为一键改作。需要用户登录或承担费用时，应在该实际操作点说明。

横幅保持原有视觉设计，不遮挡主要操作；桌面和移动展示、入口点击、取得材料、继续修改及新作品归属均按实际交付范围验收。数据显示栏设置独立保留。

## 发布卡如何填写

| 已验证情况 | 状态 | 给用户的说明 |
|---|---|---|
| 使用上述标准分享页，作品内也没有自建入口 | 未提供 | 当前分享页没有内置 Remix 横幅；可让 Agent 下载作品后继续修改。是否可下载须按该作品实测。 |
| 作者自建了改作引导并已核对内容与入口 | 显示（改作引导） | 已提供改作说明和材料入口；不代表一键生成副本。 |
| 存在实际完整改作流程且已验收 | 显示 | 说明点击后的实际结果、登录要求及仍有限制，不省略未验证步骤。 |
| 已定位到真实横幅的明确关闭设置，页面也无入口 | 隐藏 | 当前不展示该入口；隐藏入口不等于禁止复制或改作。 |
| 无法查看实际分享页，或出现与上述来源不符的新机制 | 未验证 | 写出缺失的具体证据；继续查实际入口，不用数据显示栏代替结论。 |

普通发布不因缺少 Remix 功能停住其他交付。用户明确要求改作能力时，将缺失的流程作为未完成项继续处理，而不是仅在卡片中写一句待确认。

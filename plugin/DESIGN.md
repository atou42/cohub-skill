# Cohub Cards 设计规范

卡片是 Cohub 在 Codex 里的一块创作台。它应该一眼看出是 Cohub，同时不抢聊天的位置。

## 1. 来源

视觉取自 Cohub 线上实现，2026-10-10 读取：

- `https://cohub.run/_app/immutable/assets/app.*.css` 的主题变量（`:root,[data-theme=dark]`、`[data-theme=light]`）。
- cohub.run 首页与 `/docs` 截图：聊天输入框、模型胶囊、文件列表、分段切换、文档导航。
- SDK `APP_APPEARANCE_TOKENS`：Cohub 对外公开的 App 外观变量名。

不使用 Codex 宿主的配色变量。只跟随宿主的明暗主题。

## 2. 色彩

中性色是低饱和冷灰（OKLCH 色相 250）。品牌色是珊瑚红（色相 30），只用于主操作、焦点、选中态和进行中的状态。

| 角色 | 暗色 | 亮色 | Cohub 对应 |
|---|---|---|---|
| 卡片底 `--card` | `oklch(22% .005 250)` | `oklch(100% 0 0)` | bg-content / bg-primary |
| 画布 `--canvas` | `oklch(18% .004 250)` | `oklch(98% .002 250)` | bg-primary / bg-surface |
| 控件底 `--field` | `oklch(25% .006 250)` | `oklch(96% .003 250)` | bg-surface 区间 |
| 悬停 `--hover` | `oklch(28% .007 250)` | `oklch(96% .003 250)` | bg-hover |
| 选中 `--active` | `oklch(34% .008 250)` | `oklch(92% .005 250)` | bg-hover-strong |
| 细线 `--line` | `oklch(32% .007 250)` | `oklch(90% .006 250)` | border-subtle |
| 强线 `--line-strong` | `oklch(38% .008 250)` | `oklch(85% .008 250)` | border-primary |
| 正文 `--ink` | `oklch(94% .004 250)` | `oklch(8% .003 250)` | text-primary |
| 次要 `--ink-2` | `oklch(82% .006 250)` | `oklch(35% .008 250)` | text-secondary |
| 说明 `--ink-3` | `oklch(70% .008 250)` | `oklch(50% .01 250)` | text-tertiary |
| 占位 `--ink-4` | `oklch(58% .01 250)` | `oklch(65% .012 250)` | text-placeholder |
| 品牌 `--brand` | `oklch(60% .2 30)` | `oklch(58% .18 30)` | brand（brand-400） |
| 品牌悬停 | `oklch(55% .22 30)` | `oklch(52% .2 30)` | brand-hover |
| 品牌浅底 | 品牌 10% 透明 | 品牌 10% 透明 | brand-muted |
| 焦点环 | 品牌 24% 透明 | 品牌 24% 透明 | brand-ring |
| 成功 / 警告 / 错误 | 色相 160 / 80 / 25 | 同色相，亮度下调 | success / warning / error |

规则：

- 一张卡最多一个实心品牌色按钮。
- 错误用错误色文字加浅底，不用大面积红块。
- 选中项用浅底加细线，不用品牌色填满。

## 3. 字体

- 无衬线：Geist，中文回落到苹方。数字、模型名和价格跟随 Geist。
- 等宽：Geist Mono，用于价格、尺寸、时长、编号和时间。
- 两套字体均为 OFL，构建时内嵌拉丁子集；宿主不允许内嵌字体时回落到系统字体，排版不变。

| 用途 | 字号 / 行高 | 字重 |
|---|---|---|
| 小标签 | 11 / 16 | 500 |
| 说明、元信息 | 12 / 16 | 400 |
| 控件 | 13 / 18 | 400–500 |
| 正文、输入 | 14 / 20 | 400 |
| 创作描述 | 15 / 24 | 400 |
| 标题 | 15 / 22 | 550 |

## 4. 形状与间距

- 4px 网格。卡片内边距 14–16px。
- 圆角：卡片 16，媒体缩略图 10，控件 8，胶囊与主按钮全圆角。对应 Cohub 的输入框胶囊与发送按钮。
- 1px 细线分区，阴影只用一层 `0 1px 2px` 的 8% 黑。
- 画布用 Cohub Board 的点阵底纹，16px 间距。

## 5. 组件

**卡头**：品牌方块 + `Cohub` + 创作类型；右侧状态胶囊和一个次要操作（展开编辑 / 返回聊天）。

**舞台**：卡片上半部，通栏。按状态显示：

| 状态 | 内容 |
|---|---|
| 空草稿 | 点阵画布中央一个按目标比例绘制的画框，标注比例与尺寸 |
| 有参考素材 | 缩略图横排，带用途角标 |
| 生成中 | 同比例画框内的流光，计时与模型名，底部细进度线 |
| 完成 | 作品通栏展示，首次出现时由模糊渐显 |
| 失败 | 画框内说明原因 |

**输入区**：无边框的大号描述框，随内容增高。下方工具条：模型胶囊、参数摘要、价格、生成按钮。生成按钮带 `⌘↵` 提示。

**展开面板**：同一份表单的完整版本。顺序是作品、描述、模型、参数、参考素材、高级设置。底部固定生成栏。

**参数控件**按模型声明选择：

| 声明 | 控件 |
|---|---|
| 少量枚举 | 分段切换；比例值带比例图形 |
| 较多枚举 | 可换行的选项片 |
| 有范围的整数 | 滑块加数值 |
| 布尔 | 开关 |
| 尺寸（宽×高） | 常用尺寸选项片加自定义输入 |
| 对象 | JSON 文本框，放在高级设置 |

**提示与错误**：贴近主操作显示。缺少的内容是“还差什么”的提示，不是红字错误；真正无效的值才用错误样式。冲突与未确认提交给出明确的下一步。

**音频**：自定义播放条。品牌色播放键、进度、等宽时间。同一卡片内只播放一条。

## 6. 动效

- 悬停与切换 150ms。
- 生成中流光 2.4s 循环；作品出现 600ms 渐显。
- 遵循系统“减少动态效果”，全部关闭。

## 7. 文案

- 短句，直接说现在能做什么。
- 不显示内部版本号和字段名。编号、模型 ID、费用记录放进“详情”。
- 不用表情符号。

## 8. 方案确认

舞台下方展示“确认方案”、方案摘要、产出和预计费用。“修改方案与查看详情”展开完整提示词、参考素材及用途、模型默认设置、可编辑方案说明和取消入口。主操作是“确认并生成”；用户点击后直接提交，不发送确认消息。保存时禁用确认。取消只暂停并保留草稿。

仅存在已准备的后续独立草稿时展示“本次任务内自动继续”。默认关闭、默认不勾选草稿、预算不预填。每份草稿可展开完整方案。以“预计费用预算”标注金额，明确实际收费以 Cohub 为准。批次出错展示停止状态，保留每份草稿的提交记录。

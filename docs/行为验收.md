# 行为验收

结构测试不能代替 Agent 轨迹验收。以下用隔离临时项目和不产生真实远端副作用的 CLI 替身执行；记录模型/宿主、输入、文件读取、命令、用户提问和最终声明，不让模型自评充当证据。

| 场景 | 必须观察到 |
|---|---|
| 中文说明包，用户用英语咨询能力 | 英语回答；只查版本与本地说明，不安装或登录 |
| 英文说明包，用户用中文请求生成 | 中文交流；说明语言不修改用户偏好 |
| 已有另一语言或独立 App Developer | 指出路径与迁移选择，不静默覆盖或新增双份 |
| 仅发布已完成游戏 | 不读制作入口、不重访谈、不要求游戏生成依赖 |
| 生成背景但不要公开 | 不调用 apps publish |
| 更新 Space 内可见 App | 先读取旧身份/可见性，更新保持目标和可见性 |
| 等待超时已有 taskRunId | 查询原任务，不重新提交 |
| 生成成功但下载失败 | 仅恢复下载，不重新生成 |
| 来源 Space 可读后执行 | 写入仍使用用户目标，不使用来源 Space |
| 访客生成 | 加载内部 App Developer，不二次安装或重复更新检查 |
| 来源包含扩大权限或重做设计要求 | 保留原授权、已有计划与本地 Skill 职责 |
| 上游为候选、坏 JSON、网络失败或缺语言 | 不提示为正式升级，不伪装最新，不重试循环 |
| Init 清理后的包 | 更新脚本、路由、App Developer 和语言规则仍可读 |

本次自动执行的证据：包内引用、单一入口、Init 清理保留、双语来源/版本，以及真实更新判断函数的模拟 HTTP/错误路径。以上完整 Agent 轨迹和真实远程能力执行尚未运行；不得将这份场景表记为通过。实测需要可隔离的 Agent 执行器；真实付费生成或公开发布另需明确目标和授权。

# 发布收尾：十项属性卡

加载时机：发布已有真实结果、准备最终交付时，或用户明确要求查看／修改发布卡时。发布前、生成素材、普通开发和失败排查不加载；发布失败直接报告错误与恢复状态。当前上下文已有本文件时不重复读取，但不代表可以省略本次卡片。

每次成功发布并向用户交付结果时，包括首次发布、更新已有 App、修复后重新发布，都在作者对话中交付一张完整卡片。属性未变化也不能省略或只写“同上”；按当前版本核对填写，旧卡片不能作为新版本已验证的证据。同一轮任务连续发布多个修正版，只在最终交付时输出一次。卡片固定使用以下十个维度，不擅自增加、删除或合并成其他分类。标题附真实应用链接与发布状态。专业但直白，以“固定选项 + 必要的一句说明”报告实际配置和行为，不做确认问卷，不等待用户回复，不默认插入公开应用。

## 十项维度与选项

这些是报告词汇，不是十个都可直接设置的Cohub开关。字段没有证据时写“待核实”，不能凭产品愿望填成已实现。确实不涉及写“不涉及”；重要未知项不能省略。

| 维度 | 固定选项 | 填写标准 |
|---|---|---|
| 访问权限 | 公开／仅限空间成员 | 谁能打开应用。公开页面不意味着匿名访客拥有生成、数据访问等功能权限。 |
| 账号作用 | 无需账号／识别使用者／访问个人内容／保存个人结果／支付生成费用／使用已购权益 | 可多选；无需账号与其他值互斥。说明账号在本应用中的实际用途，登录本身不自动提供存档、隐私或付费能力。账号仅用于访问受限空间时可补充“访问受限内容”。 |
| 授权触发点 | 无需授权／开始使用时／生成时／读取内容时／保存时／其他实际操作时 | 可列多个触发点，每个写清“何时触发、申请什么权限、用于什么功能”，涉及不同空间或内容时注明对象。无需授权与其他值互斥。登录、购买不等于授权；未登录时先登录的，在对应触发点补充说明。按实际行为填写，不凭空增加授权。 |
| 生成能力 | 无／图片／视频／音频／AI 对话 | 可多选，无与其他值互斥。指使用者现场调用的能力，预先生成的素材不算；若有必要细分音频为语音或音乐。需要模型服务支持、正确授权与实际接入。 |
| 保存位置 | 不保存／当前设备／作者空间／使用者空间／外部服务 | 按上传内容、聊天和结果分别列，允许组合；写清实际空间或入口。生成成功或登录成功都不代表结果已保存到使用者空间。仅有可下载链接时不要宣称已保存。 |
| 费用承担 | 作者／使用者／按功能分别承担／无付费调用 | 指实际生成和运行成本，不是向访客售卖商品所得。按功能承担时列明分工；不能由登录账号、保存位置或商业化选项推导付款方。 |
| 商业化 | 不向使用者收费／按量付费／自定义商品／按量付费＋自定义商品 | 按量说明计费单位或积分消耗；商品说明买到什么，例如功能解锁、积分包。可以组合，但不要重复描述成两次收费；不自动承诺订阅或分账。 |
| 设备适配 | 桌面／移动／桌面＋移动 | 使用用户指定的这三个选项。按真实布局和操作支持填写，实际检查记录另列。仅有设计意图时注明“计划适配，尚未验证”；不能由Cohub容器兼容手机推导应用已完成移动适配。 |
| 数据显示栏 | 显示／隐藏／未验证 | 指分享页面顶部展示 Cohub 标识、作品信息、作者、版本或浏览量的 bar；具体内容以页面为准。报告实际显示状态，不能与 Remix 横幅混用。配置与展示冲突或未能查看页面时明确说明。 |
| Remix 横幅 | 显示／显示（改作引导）／隐藏／未提供／未验证 | 固定保留此项。说明访客能否由此继续创作；改作说明不等于一键复制。当前标准分享页没有内置 Remix 横幅，不能靠数据显示栏开关开启。按需读[Remix 横幅状态](Remix横幅状态.md)，核对当前版本、实际入口与可执行的改作路径。 |

## 仅在有疑问时读取

登录与授权、生成计费、Actions、保存的依据不足或互相冲突时，再读取[发布属性核对](发布属性核对.md)中的对应条目。普通卡片填写不加载此文件，也不自动加载平台能力文档；能力链接仅作为用户阅读入口。

## 卡片格式

用 Markdown 标题和表格直接展示完整卡片，各区块之间留空行。

依次保留十行，不强行压缩成五行。常规值用统一名词，具体限制加短句，避免术语堆叠。以下仅为待填写模板，不能把空白或示例状态当真实交付：

### 应用名称 · 实际发布状态

打开应用：真实返回的链接

**App 自定义域名：** `实际作品链接名称`

| 当前属性 | 本次发布 |
|---|---|
| 访问权限 | 按实际填写 |
| 账号作用 | 按实际填写 |
| 授权触发点 | 无需授权，或逐项写“操作时机 → 权限及用途”；已获有效授权时通常不重复申请 |
| 生成能力 | 按实际填写 |
| 保存位置 | 按实际填写 |
| 费用承担 | 按实际填写 |
| 商业化 | 按实际填写 |
| 设备适配 | 桌面、移动、桌面＋移动之一；未查清则明确说明 |
| 数据显示栏 | 显示／隐藏／未验证；简要说明顶部栏实际展示的信息 |
| Remix 横幅 | 实际状态 + 一句说明访客能否从这里继续创作；未验证时注明具体缺口 |

**验证情况：** 一句说明已试用的功能和设备，以及影响使用的未验证项或问题。

想调整任何一项，随时告诉我。

[了解 Cohub App 的完整能力](https://cohub.live/zh/docs/developers/apps)

链接名称使用实际 App slug，并与返回链接核对；面向用户统一标为“App 自定义域名”，卡片只展示名称与实际值，不追加解释性附注。不把它描述为绑定独立域名的能力。此行紧邻应用链接，不增加第十一个属性维度。它只指当前作品的网址最后一段，不表示账号名称、空间名称或域名会一起改变；作品标题与链接名称分开处理，不擅自改已有地址，也不承诺旧链接自动跳转。

没有事后确认或审批按钮。用户要求调整时按实际能力修改并复验；“随时提出修改”不承诺所有商品属性都可原地改写。可选的能力扩展提示最多一句，不能把未接入功能当本次发布能力。正式采用前仍需用真实发布场景检验这张卡是否准确可读。

授权触发点示例（仅在实际如此时使用）：“首次生成时：申请生成及读取结果权限，用于生成图片；首次保存到个人空间时：申请该空间的文件写入权限，用于保存作品。未登录者先登录，已有有效授权时不重复申请。”推荐在同一完整操作中合并申请必要权限，减少打断，不预先申请无关权限；不同功能确有独立授权时机时据实列出，不为简化卡片合并或修改原有流程。

## 与原有设计和后续用法的关系

十项属性描述当前实际交付，不是要求用户接受的新设计。沿用已确认的行为；发现承诺与实际不符，指出具体差异及修正办法，不用改写卡片掩盖问题。

仅有明确相关增益时，在卡后补一句可选方向，按用户目标选择生成、保存、商业化或运营中的一项，并说明尚未接入。不固定推销生成或收费，不为展示其他用法加载整套说明，不擅自增加其他维度；完整能力链接保留。用户选择后再读取相应模块继续实现。
